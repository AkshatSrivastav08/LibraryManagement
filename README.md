📚 Library Management System – C++ (CLI Based)
A simple yet functional Command-Line Interface (CLI) based Library Management System written in C++, designed for managing books with persistent storage using file handling. This project supports complete CRUD operations along with book issuance and return tracking.

🚀 Features
📖 Add, view, update, and delete books

🔍 Search book by ID

📦 Persistent data storage using binary files (books.dat)

✅ Issue and return book functionality

💻 Simple and beginner-friendly CLI interface

💾 Uses C++ file I/O for data handling

🛠️ Tech Stack
Language: C++

Concepts Used: OOP (Object-Oriented Programming), File Handling, Data Structures
